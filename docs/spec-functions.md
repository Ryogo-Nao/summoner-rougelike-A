# 召喚士ローグライク 機能仕様書

基準の版：v105（2026-11-11）。ここまでを基盤として拡張する。

この文書は「プレイヤーが何をできて、どうなるか」をまとめる。動く仕組みは [処理仕様書](spec-processing.md)、画面の形は [画面仕様書](spec-screens.md)、数値は [balance.md](balance.md)、決めたことの経緯は [requirements.md](requirements.md) を見る。

機能の番号（例：D-03）は、この文書の中の呼び名。テストの番号（test-plan.md の F-xx）とは別にする。

## 1. ゲームのあらまし

- 主人公は召喚士。ダンジョンで魔物をカードに封印して仲間にし、いちばん下の階をめざす
- MP は「召喚」と「魔法」の両方に使う。この取り合いが遊びの中心
- ダンジョンに入るたびに主人公は Lv1 から始まる。仲間・覚えた魔法・道具・ルーンは拠点に持ち帰れる
- 遊びの流れ：拠点で準備 → ダンジョン → 拠点に戻る（踏破・離脱・あきらめた・力つきた）→ 配合・売り買い → また準備

### 4.7 ダンジョンの終わり方
| 終わり方 | 起きること | 持ち帰るもの |

## 6. 世代継承など（まだ作っていない）

拡張の予定として requirements.md 9章に書いてある。今の作りで入れ物だけあるもの：
- 世代（`generation`）：拠点の名札に「初代」と出す。継承の仕組みはまだない
- 称号・ミッション：トップの名札のまわりと、トップの右上の空いた札の場所を空けてある
