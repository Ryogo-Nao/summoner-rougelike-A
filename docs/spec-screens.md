# 召喚士ローグライク 画面仕様書

基準の版：v105（2026-11-11）。ここまでを基盤として拡張する。

この文書は「画面に何がどう並び、押すとどこへ行くか」をまとめる。できることは [機能仕様書](spec-functions.md)、動く仕組みは [処理仕様書](spec-processing.md)、絵と色の素材は [art-guide.md](art-guide.md) 8章、決めたことの経緯は [requirements.md](requirements.md) 10章を見る。

画面の番号（例：S-21）は、この文書の中の呼び名。

## 1. 共通の決まり

### 1.1 画面の前提
- iPhone の縦持ち。幅いっぱいを使い、横にスクロールさせない
- 画面の上下の安全な余白（ノッチ・ホームバー）を空ける
- Safari の上のバーの色は、ダンジョンでは上の帯と同じ紺、拠点では村の絵の空の色
- 長押しのルーペや文字の選択が出ないようにする

### 1.2 見た目の部品（紺と金）
拠点もダンジョンも、紺の地に金の線の共通の部品にそろえる（art-guide.md 8.2・8.3）。

| 部品 | 見た目 | 使うところ |
|---|---|---|
| 主役のボタン | 空色の宝石（楕円）、金の縁 | 1つの画面に1つだけ。出発・買う・売る・出す・しまう・確かめの左 |
| ふつうのボタン | 暗い紺のタブの板 | 横いっぱいのボタン、［閉じる］、選ぶ・使うなど |
| ［やめる］ | 赤い宝石（主役と同じ形） | 確かめの右、ダンジョンの詳しい画面の右、別れる画面の右 |
| 注意のボタン | 赤 | メニューの［ダンジョンをあきらめる］だけ（押すと確かめの窓が出る） |
| 控えめなボタン | 左上の「‹」 | 一つ前の一覧へ戻る |
| 押せないボタン | 暗くして字を薄く。押せない理由をボタンの字にする（例：［MPが足りない］） | — |
| 紙の行 | 明るい紙の地。1枚の紙を細い線で区切る | 一覧の行（1.3） |
| 枠 | 四隅に金の唐草の紺の枠 | 一覧（シート）・ログの一覧・確かめの窓 |

### 1.3 確かめのボタン（2026-11-11）
- どの確かめも、左に取り消せない操作（降りる・あきらめる・配合する・転生する・別れる）を主役の空色で、右に［やめる］を赤で置く
- 赤は［やめる］の色にし、取り消せない操作には使わない（メニューの［ダンジョンをあきらめる］は例外で、赤のまま）
- ダンジョンの詳しい画面の［準備する］［やめる］も同じ並びと色

### 1.4 一覧の1行
| 位置 | 中身 |
|---|---|
| 左 | 顔（仲間）か道具の絵。絵がなければ絵文字 |
| まん中の上 | 名前（大きく太く）と、横に小さな札（Lv・×3・装備中・値段・n個まで） |
| まん中の下 | 説明を1行（入りきらなければ「…」）。どの行も同じ高さ |
| 右 | ボタン、丸い印（連れていく・選ぶ）、［－］数［＋］、押すと開く行は「›」 |
| 選んでいる行 | 淡い金にして左に金の線 |
| 使えない行 | 暗くする |

- 同じ道具は「薬草 ×3」と1行にまとめる。分けるのは、装備しているもの・＋の違う装備・入る数の違う袋・中身のある袋・矢の束
- 道具の一覧は、はじめは種類順（道具の表の順）
- 一覧はページに分けずスクロールする。ほかの画面を見て戻ったときは、もとのスクロールの位置に戻す

### 1.5 数を選ぶ［－］数［＋］
- 紺の小さな［－］［＋］と、まん中に薄い紙の箱の数
- 数を押すと、じかに打ち込める（全角の数字も読む）
- 選べる数をこえて打ち込んだら、数は変えずに名前の横に「n個まで」を赤で出す
- 使うところ：商店（買う・売る）、拠点の持ち物、ダンジョンの袋（出す・しまう）

### 1.6 字
- 小さな情報（見出し・ルーン・名札・Lv・タブ）：丸くない太いゴシック（Zen Kaku Gothic New の Black）
- 拠点のトップの看板と札：文字ごと1枚の絵（art-guide.md 8.1）
- 本文：端末の字

## 3. 拠点の画面

### 3.0 拠点の共通の枠（#base）
| 場所 | 中身 |
|---|---|
| 上の左（#base-title） | 画面の名前（拠点・冒険の準備・仲間・配合・商店・その他）。紺の板に金の縁 |
| 上の右（#base-runes） | 持っているルーン。商店で数を選んでいる間は「5000 → 4960」 |
| 上のタブ（#base-tabs） | 冒険の準備のときだけ［仲間］［持ち物］と、左に「‹」（ダンジョンを選び直す） |
| まん中（#base-body） | 画面ごとの中身。トップ以外は背景（村の絵）を少し暗くする |
| 下のボタン（#base-depart） | 冒険の準備：［〇〇へ出発］。商店：［n個を買う 💠合計］［n個を売る 💠合計］。つよさ・袋の中・道具の説明を見ているとき：［戻る］ |
| 下のタブ（#base-nav） | ［拠点］［冒険］［仲間］［商店］［その他］。木の帯に四角い枠のアイコンと名前。知らせの印を付ける |

### S-01 拠点のトップ
- スクロールさせない。画面の高さに合わせて縮め、1画面に収める
- 上：魔法陣の台の上の主人公、名札「初代 召喚士」（称号はここに足す）、連れていく仲間の5枠（顔と Lv。4・5枠目は控えとして少し離して薄く）
- まん中：鎖で吊るした［冒険の準備］の看板
- 下：2×2 の札［商店］［（空き）］［記録］［配合］。右上は空けておく（ミッションなどを置く予定）
- 知らせ：［配合］に「NEW」のリボン、［商店］に赤い丸

### S-02 ダンジョンを選ぶ
- 「挑むダンジョンを選ぶ」のリボンの見出しの下に、ダンジョンごとの行
- 行：🏆 踏破済み／⚔️ 挑める／🔒 まだ（条件を出す）、名前、階の数
- 押すと S-03

### S-03 ダンジョンの詳しい画面
- 名前、踏破したか、階の数、魔物の Lv、特徴、記録
- 下に、左［準備する］（空色の宝石）、右［やめる］（赤い宝石）。［準備する］で S-04、［やめる］で S-02

### S-04 冒険の準備（仲間）
- 上に固定：「連れていく n / 5」と顔5つの枠（選んだ順。4・5体目は控え）、検索の欄と並べ替えのボタン
- 行：顔、名前と Lv、「HP29　💧水」。右に丸い印（金の丸に緑のチェックで連れていく）
- 行を押すと S-10。顔の枠を押すと外れる
- 並べ替え：レベル・仲間にした順・名前・種類（それぞれ逆も）

### S-05 冒険の準備（持ち物）
- 上に固定：［🎒 バッグ 数/40］［📦 倉庫 数/9999］の切り替え、検索の欄、並べ替え（種類順・名前順・個数順）
- 行：同じ道具を1行にまとめ、右に［倉庫へ送る］か［バッグへ］。袋は中を開ける（袋の中も出し入れ）
- 行を押すと S-11

### S-06 仲間の一覧
- 上：［一覧］［配合］［転生］の切り替え（配合・転生は S-07）
- 上に固定：検索の欄と並べ替え
- 行は S-04 と同じ（連れていく仲間は金の光で縁取る）。丸い印で連れていく・残す

### S-07 配合・転生
- 上：「必要 📗配合の書 1（持っている 0）　💠1000（持っている 336）」
- 親を2体選ぶ（転生はイヅツチと合わせる1体）。Lv10 未満は選べない
- 生まれる子の見込み（明るい紙の札）：名前（「ガルフ+1」）、足し算、伸び。性格の確率は出さない
- ［配合する］［転生する］（空色の宝石）→ 確かめの窓 S-51
- 終わったら一言（生まれた子と性格）
- まだ生んでいない別の種族は「？？？」

### S-08 商店
- 上：［買う］［売る］の切り替え（紺のタブ）
- 買う：送り先［🎒 バッグへ送る］［📦 倉庫へ送る］。棚の品を1つずつ1行（薬草・パンは2行ずつ）、名前の横に💠値段、右に［－］数［＋］（どの行も1まで）。買えない品は暗くして［＋］を押せない
- 売る：［🎒 バッグ］［📦 倉庫］の切り替え。同じ道具を1行にまとめ、「×3」と［－］数［＋］。売れない道具は［売れない］
- 下のボタン：［n個を買う 💠合計］／［買う品を選ぶ］（押せない）、売るも同じ
- いつでも買える品と入れ替わる品を、画面では分けて書かない

### S-09 その他
- 上：［記録］［設定］の切り替え
- 記録：主人公の絵と「初代 召喚士」、ダンジョンに入るときの能力、覚えている魔法（無印で）、累計（潜った回数・たおした魔物・仲間にした数・拾った道具・拾ったルーン）、ダンジョンごとの戦績
- 設定：5つの設定（機能仕様書 C-05）。オン・オフは切り替えスイッチ、選ぶものは横並びのボタン（今の選択は紺に金の字）。その下に遊び方

### S-10 仲間のつよさ
- 名前（［✎］でニックネーム。8文字まで、こえると赤で押せない）
- Lv・経験値・HP・攻撃・防御・魔攻・魔防・性格・属性・召喚の MP・速さ・特技・強み
- ダンジョンでは、召喚中なら指示と状態異常、入手（連れてきた・このダンジョンで仲間にした）も出す
- 拠点では下の［戻る］、ダンジョンでは「‹」で元の一覧へ

### S-11 道具の説明
- 道具の絵・名前・詳しい説明。下の［戻る］で元の一覧へ

## 4. ダンジョンの画面

### S-20 ダンジョン（#app）
```
┌───────────────────────────┐
│ [B3F]              💠12  52T │ ← 上の帯（#status）
│ (顔)Lv5  HP ■■■■□ 32/40     │
│          MP ■■□□□ 12/30     │
│          満腹 ■■■■□ 80%     │
├───────────────────────────┤
│ (顔)ついてくる (顔)…  (＋)召喚 │ ← 仲間の枠3つ（#allies）
├───────────────────────────┤
│[見通し]              ┌ミニ┐ │
│                      └マップ┘│
│     マップ（主人公が中央）    │ ← #map（キャンバス）
│ ┌ログの最後の2行────────┐ │ ← #log（マップの下の端に重ねる）
├───────────────────────────┤
│  ↖ ↑ ↗      [   攻撃   ]    │ ← 操作部（#controls）
│  ← ● →    [魔法] [仲間]     │   パッド（#pad）とボタン（#buttons）
│  ↙ ↓ ↘   [バッグ][メニュー]  │   設定でパッドを右にすると左右が入れ替わる
```

| 場所 | 中身 | 押すと |
|---|---|---|
| 階（#floor） | 「B3F」の紺の札 | — |
| ルーン・ターン（#runes・#turn） | 拾ったルーン、ターン | — |
| 主人公 | 丸い顔、左下に Lv の札、HP・MP・満腹の棒と数。強化・状態異常の印（#effects） | — |
| 仲間の枠（#allies） | 丸い顔・Lv の札・HP の棒・状態異常の印。HP の上に今の指示。空いた枠は「＋ 召喚」 | 仲間がいれば指示の一覧 S-38、空きならカードの一覧 S-30 |
| ［見通し］（#btn-look） | オンの間は金の地 | オン・オフ（ターンは使わない） |
| ミニマップ | 右上。主人公は明るい緑、仲間は濃い緑、敵はピンク、道具は水色、階段は黄色 | 大きくする・戻す |
| マップ（#map） | 主人公・仲間（足もとに緑の影）・魔物（赤い影）・道具・階段。主人公の向きを金の矢印、正面のマスを金の枠（設定） | 隣の仲間を押すと S-39 |
| ログ（#log） | 最後の2行。半透明の紺の札 | S-22 |

| ［攻撃］（#btn-attack） | 空色の宝石の大きなボタン | 短く押す：攻撃。長押し：扇（左上・上・右上の3枠に登録した道具） |
| ［魔法］［仲間］［バッグ］［メニュー］ | 紺の小さなボタン | S-31・S-30・S-32・S-37 |

マップの描き方：
- 主人公・仲間・魔物は1マス約0.12秒でなめらかに歩き、小さく跳ねる。立っている間は息をするように伸び縮みする
- 絵は左下を向いている。右を向いたら左右を反転する
- 攻撃は、主人公・仲間・魔物の順に1回ずつ見せる（構える → 飛ぶ → 当たる）。ダメージの数字、よく効いた（橙）・効きにくい（灰青）
- 明かり：主人公のまわりは明るく、離れるほど暗い。たいまつ。まだ見ていないマスは強く暗く
- 床・壁の色と明かりは、ダンジョンごと（dungeons.ts の theme）

### S-21 階の名前（#floor-title）
- 紺の画面に、ダンジョンの名前と「B2F」（階は金の字）を約1.6秒。最後に薄くなって消える。タップすると早く消える

### S-22 これまでのログ（#log-history）
- ターンが変わるところに見出し。いちばん新しい行が見えるところから始める
- ［閉じる］か外側のタップで閉じる。ダンジョンが終わっていたら、終わりの知らせをもう一度出す

## 7. 拡張するときの決まり

- 新しい拠点の画面は、#base の枠（見出し・ルーン・下のボタン・下のタブ）の中に作る。下のタブは5つのまま増やさない（入れるなら今のタブの中の切り替えにする）
- 新しい一覧は 1行の形（`lines: true`）で作る。道具は `groupItems` で同じ道具をまとめ、数を選ぶなら［－］数［＋］（`countStepper`）
- 主役のボタンは1つの画面に1つだけ。確かめは 1.3 の並びと色
- トップの空いた札の場所（右上）と、名札のまわり（称号）は、これから足すもののために空けてある
- 画面を足したら、この文書の 2章の表と行き来の図、requirements.md 10章に書き、画面のテスト（tests/e2e）を足す
