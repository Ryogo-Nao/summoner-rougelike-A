# 召喚士ローグライク（仮） 要件定義 v0.4

最終更新: 2026-11-02

数値の設計は [balance.md](balance.md) を参照。

## 1. コンセプト
- 主人公は**召喚士**。魔物を**カードに封印**して仲間にする
- **MP**は「召喚」と「魔法」の両方に使う。この取り合いがゲームの面白さの中心
- 仲間は消耗していく戦力で、**どのカードをどこで切るか**が戦略になる
- 世界観・キャラクター・魔物・名前はすべてオリジナル

## 2. 基本仕様
| 項目 | 内容 |
|---|---|
| 環境 | iOS Safariを主な対象にしたWebアプリ（PWA）。オフラインで遊べる |
| 画面 | 縦持ち、絵文字で表示（MVP） |
| 操作 | バーチャルパッド（8方向）＋アクションボタン |
| 1回のプレイ時間 | 約30分（目安は10〜12階）。高難度ダンジョンは対象外 |
| セーブ | 毎ターン自動保存し、中断から再開できる |
| 開発方針 | まずMVPを作る |

### 2.1 ホーム画面とオフライン（今の作り）
- Safariの共有メニューから「ホーム画面に追加」すると、アプリのように全画面で開く。名前は「召喚士」、アイコンは金色の魔法陣
- 一度通信できるときに開けば、そのあとは通信できなくても遊べる
- 通信できるときは、開くたびに新しい版を取りに行く。公開した更新は、次に開いたときに入る
- アイコンは scripts/make-icons.py で作る（public/icon-*.png）

## 3. 主人公
- 能力値：HP / MP / 満腹度 / レベル / 攻撃力 / 防御力 / 経験値
- 満腹度は時間とともに減る
- **満腹度が1以上**ならHPが自然回復する
- **満腹度が0**になるとHPが毎ターン減っていく
- ダンジョンに入るとレベル1から始まる

## 4. MP
- 使い道
  - 召喚のコスト（魔物ごとに違う）
  - 魔法：攻撃魔法（例：火）、強化魔法（例：攻撃力アップ・防御力アップ・魔攻アップ・魔防アップを数ターン）
  - 主人公・仲間・魔物は、攻撃力・防御力のほかに**魔攻・魔防**を持つ。攻撃の魔法・火を吐く・いかずちのダメージは魔攻と魔防で決まり、ふつうの攻撃は攻撃力と防御力で決まる（balance.md 3.6）
  - 属性（火・水・雷・土・風・光・闇・無）がある。強い相手へ ×1.5、効きにくい相手と同じ属性へ ×2/3。主人公は無属性で、魔法・武器・盾の属性が乗る。魔物と仲間は種族の属性（balance.md 3.7）
- 回復手段：**アイテムのみ**（MVP）
  - 今後、魔物の特殊能力で回復する手段を追加する予定

### 4.1 魔法の習得
- 最初から使える魔法：**ヒボシ**（目の前の敵に火）
- 使える魔法が増える方法
  | 入手元 | 使える期間 |
  |---|---|
  | アイテム（魔導書など） | 使って習得すると、以後ずっと使える |
  | 武器・防具（杖） | 装備している間（覚えていなくても使える。balance.md 6.7） |
  | 召喚している魔物の能力 | その魔物が召喚されている間 |
- 魔導書で覚える魔法：イテホシ（氷）・ホシキリ（風）・ホシナリ（雷）・ホシヨビ（土）・チカラボシ・マモリホシ・イノリホシ・カゴホシ（balance.md 2.1）
- 覚えている魔法の魔導書をもう一度読むと、**＋値**が上がる（無印、+1、+2）。＋値はそのダンジョンの間だけで、拠点に戻ると無印に戻る。火の魔導書はヒボシを強くする。詳細は balance.md 2.2
- 魔導書はダンジョンでめったに出ない（ほかのアイテムに対して2〜3％）

## 5. カード（封印）システム
### 5.1 封印の方法
1. **封印カード（白紙）を使う**：敵に使って封印する
2. **倒したときのドロップ**：敵が強いほど確率が下がる。全体的に**かなり低い確率**にする

### 5.2 捕獲率（封印カードを使ったとき）
- **魔物ごとに基本の捕獲率**を設定する
- 敵のHPが減るほど、捕獲率が上がる
- **HPが15％以下になると、捕獲率が3〜5倍**になる
- 計算式の案（hはHPの残り割合 0〜1）
  - h > 0.15 のとき：捕獲率 = 基本捕獲率 × (1 + (1 − h))　→ 最大で約1.85倍
  - 0.01 < h ≦ 0.15 のとき：捕獲率 = 基本捕獲率 × (3 + 2 × (0.15 − h) / 0.14)　→ HP15％で3倍
  - h ≦ 0.01 のとき：捕獲率 = 基本捕獲率 × 5（最大）。HPが1でも、最大HPが100より少ない魔物では1％を超えるので最大にならない
  - 上限は100％

### 5.3 カードの記録内容
- 魔物の種類 / レベル / 経験値 / 現在のHP / 状態 / 持ち込んだカードか、このダンジョンで入手したカードか

### 5.4 カードの状態
| 状態 | 説明 |
|---|---|
| 待機 | 手元にあり、召喚できる |
| 召喚中 | フィールドに出ている |
| 瀕死 | 倒れてカードに戻った状態。そのダンジョンでは召喚できない |

### 5.5 ルール
- **魔物カードの所持：最大5枚**
- **白紙の封印カード**：通常のアイテムとしてバッグに入る。5枚の上限には含めない（上限はバッグの容量）
- **同時召喚数：3体まで**
- 出し入れは自由。ただし召喚するたびにMPを消費する
- **ダンジョンに入るとき**：連れていく仲間（5体まで）のうち、選んだ順の最初の3体は、召喚した状態で一緒に入る（MPは使わない）。主人公と合わせて最大4人で始まる。4体目・5体目は待機のカードとして持っていく。ログに「チュッピ・イヅツチ・パタリも一緒に入った」と出す
- 仲間のHPは自然回復しない。カードに戻しても、減ったHPはそのまま
- **ダンジョンを出ると瀕死から元に戻る**
- 仲間のレベルは**ダンジョンを出たあとも残る**

### 5.6 6枚目を手に入れたとき
- 手持ちの5枚と新しいカードから、**外す1枚を選んで入れ替える**
- **ダンジョンに持ってきたカード**は、外すと**拠点の保管庫**に預けられる
- **そのダンジョンで手に入れたカード**は預けられない。外すと**その仲間と別れ**、カードはなくなる（もう一度聞いてから別れる）
- ダンジョンに入るときに、保管庫から持っていく5枚を選び直せる

### 5.7 主人公が倒れたとき
- **持ち込んだカード**：そのまま残る。そのダンジョンで上げたレベルも残る
- **そのダンジョンで入手したカード**：失う（保管庫には預けられないので、手元のものだけ）
- **バッグのアイテム**：ランダムに半分を失う
- **そのダンジョンで拾ったルーン**：半分を失う（端数は失う側）

### 5.8 ダンジョンをあきらめたとき
- メニューの［ダンジョンをあきらめる］で、確認を出してから拠点に戻る
- **ダンジョンに入る前に戻す**：そのダンジョンで手に入れたカード・道具・ルーン、上がったレベル、覚えた魔法は残らない（拾ったルーンは、すべて失う）
- そのうえで、**持っていったバッグの道具の半分**（ランダム）を失う。拠点のルーンと倉庫はそのまま（2026-11-08 に、拠点のルーンの半分を失うのをやめた）
- 聖なる袋の扱いは、力つきたときと同じ（失わない。30％でふつうの袋に戻る）
- 終わりの知らせは「B3Fで○○をあきらめた／ダンジョンに入る前に戻った／失ったもの：アイテムn個　nルーン」

## 6. 仲間の魔物
- 経験値を得て**レベルアップする**
- 経験値は**召喚中の仲間と主人公の全員で山分け**し、とどめを刺した者には通常の分け前に加えて＋50％入る
- 指示は次の4つ
  | 指示 | 動き |
  |---|---|
  | ついてくる | 主人公のそばで戦う |
  | 待機 | その場から動かない |
  | 突撃 | 敵を見つけ次第向かっていく。2マス手前で止まり、敵が近づいてくるのを待つ（敵が誰かと戦っていれば加勢する） |
  | 逃げる | 敵から離れる |
- 仲間は、眠っている（まだ起きていない魔物も）・はりつけの魔物を狙わない（攻撃・いかずち・火を吐く・突撃のどれも）。起こしたり、はりつけを解いたりしないため。主人公は攻撃できる
- 仲間が離れたところ（舌・触手・火）から攻撃されたら、その魔物に近づいて戦う（待機・逃げるのときは近づかない）
- 魔物は、主人公にも仲間にも攻撃が届くとき、3:1 で主人公を狙う（balance.md 4.4）
- 特技を持つ（MVPでは一部の魔物だけ）
- 仲間のHPを回復する手段：階段を降りたとき（ダンジョンごとの設定）、薬草を仲間に投げる

### 6.1 相棒イヅツチ
- 雷の猫。ダンジョンでは出会えない、物語のオトモ。最初から持っている
- 主人公が倒れても失わない
- 詳細は balance.md 4.0

### 6.2 仲間の能力の決まり方
仲間の能力は、補正を順にかけて求める。カードに積み上げた数値を持たず、毎回計算する。
こうすると、補正の追加や数値の調整を、育てたカードにもそのまま反映できる。

```
能力 ＝ （Lv1の値 ＋ 1レベルの伸び × 成長曲線） × 性格の補正 ＋ 足し算の補正
```

| 補正 | 持ち主 | 内容 | 見える？ |
|---|---|---|---|
| もとの強さ | 魔物の種類 | 敵のときの能力。Lv1は8割（今の決まり） | 見える |
| 成長の型 | 魔物の種類 | どの能力がよく伸びるか（HP型・攻撃型・防御型・バランス型） | 見えない |
| 成長の早さ | 魔物の種類 | 早熟（序盤に伸び、後半は鈍る）・普通・晩成（序盤は鈍く、後半に伸びる） | 見えない（図鑑や説明で匂わせる） |
| 性格 | カード1枚ごと | 封印したときにランダムで決まる。能力1つが ×1.1、別の1つが ×0.9。動きは変えない | 見える |
| 足し算の補正 | カード1枚ごと | あとで足すもの（世代継承の引き継ぎ、能力を上げる道具など） | 見える |

- 性格は封印したとき・カードを落としたときに決まる。前に作ったカードは「すなお」として読み込む
- 数値と魔物ごとの割り当ては balance.md 4.2

### 6.3 つよさ画面
- 拠点でもダンジョンでも、仲間のつよさを確かめられる
- 出すもの：絵、名前（ニックネームがあればそれ）、種族、Lv、HP、攻撃力、防御力、経験値と次のLvまで、性格（上がる・下がる能力）、召喚MP、速さ、特技、状態
- ダンジョンでは、召喚中なら指示と状態異常、どこで手に入れたか（持ってきた・このダンジョンで手に入れた）も出す
- 成長の型と早さは出さない
- 並べ方（2026-11-08、UIレビュー）：上に小さな絵と、その横に名前・「Lv11　ベロッグ　💧水」。その下に背景の文、見出しの付いたまとまり「能力値」（HP・召喚MP・攻撃力・防御力・魔攻・魔防を2列）、「育ち」（経験値・配合の回数・速さ）、「性格と特技」（性格・特技・状態、ダンジョンでは指示・状態異常・入手も）
- 拠点ではHPが減らないので、HPは最大HPだけを出す（拠点の仲間の一覧も同じ）。ダンジョンでは「今のHP/最大HP」
- **ニックネーム**：拠点のつよさ画面で、名前の横の［✎］を押すと、名前のところが打ち込む欄に変わる（8文字まで。絵文字も1文字と数える）。［決める］で名前が差し変わる。8文字をこえると数を赤にして押せなくする。空にして決めると種族の名前に戻る
  - 付けた名前は、拠点の一覧・ダンジョンの仲間の一覧・ログなど、仲間を呼ぶところすべてで使う

## 7. ダンジョン
- 部屋と通路を自動生成し、階段で次の階へ進む
- ダンジョンごとに設定する項目
  - 階数
  - **階段を降りたときに仲間のHPを回復するかどうか**と、その回復量（高難度ダンジョンでは回復なし）
  - 出現する敵・アイテムのテーブル
  - 1階に落ちているアイテムの数（はじまりの洞窟は4〜6個）
  - 出てくる魔物のレベル（はじまりの洞窟は1。難しいダンジョンほど上げる。balance.md 4.5）
  - モンスターハウスが出る階・確率・魔物とアイテムの数（balance.md 7.2）
- 魔物のレベルは、ダンジョンの難しさだけでなく階でも上げる。深い階に弱い魔物を出すときは、レベルを上げて手ごわい敵にする（例：B10F以降のチュッピはLv8）。封印した魔物はそのレベルで仲間になる
- 2つ目以降のダンジョンの構成（階数・魔物と階ごとのレベル・アイテムの表）は、Claudeが案を作る
- アイテムの出やすさは、ダンジョンごと・階ごとに変えられる（balance.md 6.2）
- ダンジョンの終わり方は3つ。拠点では、どのダンジョンを踏破したかを覚えておく（踏破しないと次に挑めない、などに使う）
  | 終わり方 | どうなったとき | 持ち帰るもの |
  |---|---|---|
  | 踏破 | いちばん下の階段を降りた | すべて |
  | 離脱 | 転送の印で脱出した | すべて（踏破にはならない） |
  | 失敗 | 力つきた | そのダンジョンで手に入れたカードとバッグの半分を失う（5.7） |
  | 失敗 | メニューで［ダンジョンをあきらめる］を選んだ | ダンジョンに入る前に戻り、ここで拾ったルーンと、持っていった道具の半分を失う（5.8） |

- あきらめるときは確認を出す。確認の窓には、押す前に失うものを数で出す（「失うもの　道具3個　💠120」。ルーンはそのダンジョンで拾った分。ここで仲間にした魔物がいれば「ここで仲間にした2体」も）。［あきらめる］は注意の赤、［やめる］は主役の空色。終わりの知らせは「B3Fで○○をあきらめた」にする

## 8. MVPで作る範囲
- ダンジョン1つ、全10階前後
- 敵（＝封印できる魔物）約8〜10種
- 魔法2〜3種
- アイテム：食料、HP回復、MP回復、封印カード、武器と盾を少し
- 町、未識別の仕組み、合成は入れない
- ただし**保管庫と、持っていくカードを選ぶ画面**は必要（簡易的な拠点画面）
- ダンジョンには**カードとアイテムの両方を持ち込める**
- 拠点には**倉庫**があり、ダンジョンで得たアイテムをしまえる。拠点ではアイテムの出し入れが自由
- 倒れたときに半分を失うのは、持ち込んだアイテムも含めたバッグの中身すべて

## 9. 今後の拡張（MVPには入れない）
### 9.1 世代継承（「一生」の概念）
- 主人公には「一生」がある。1人の主人公は、その一生の中でたくさんの冒険をし、1人の弟子を持つ
- 主人公が冒険を終える（一生を終える）ときに、弟子へ次のものを継承する
  - 持っている仲間の一部
  - アイテム
  - 魔法
  - ルーン
- 継承した回数（何代目か）を、拠点のトップの左上と名札に出す（あとで称号も左上に足す）
- 一生の長さ、弟子の選び方、継承できる量などの詳細は後で設計する

### 9.2 配合
仲間を2体合わせて、より強い1体を生む。育てきった仲間の使い道にし、弱い魔物も重ねれば終盤まで連れていけるようにする。

- **場所**：拠点の下のタブ［仲間］の上の切り替え［一覧］［配合］［転生］と、トップの［配合］の札（2026-11-08 に下のタブから［配合］を外し、仲間の中へ移した）
- **画面**：上で［配合］［転生］を切り替え、その下に「必要 📗配合の書 1（持っている 0）　💠1000（持っている 336）」のように、1回に使う数と持っている数を1行で出す（転生も同じ）。見た目は紺と金の共通の部品（docs/art-guide.md 8.2）で、生まれる子の見込みは明るい紙の札にまとめ、［配合する］［転生する］は空色の宝石のボタンにする。仲間の行（転生ではイヅツチの行も）を押すと、つよさを見られる（下の［戻る］で配合の画面へ。選んだ親はそのまま）
  - Lv10 以上の仲間（イヅツチは除く）を一覧に出し、右の丸い印で親を2体選ぶ。一覧は1行の形（10.4）で、名前と Lv を大きく、その下に性格・配合（転生）の回数・属性を出す
  - 2体選ぶと、上に生まれる子の見込みを出す：子の種族のボタン［親1の種族］［親2の種族］［別の種族］、子の名前（「ガルフ+1」）、足し算・伸び・性格の確率
  - ［配合する］を押すと「○○と○○はいなくなります　配合しますか？」と聞いてから合わせる。書・ルーンが足りないときは、ボタンに理由を出して押せなくする
  - 子は親1のいた場所に入る。連れていく仲間には入れない。親の種族を選んだときは、その親のニックネームを引き継ぐ
- **使うもの**：配合の書1つと、1000ルーン（いつも同じ）
- **親**：仲間を2体。どちらも Lv10 以上。相棒のイヅツチは親にできない（9.3 の転生を使う）。連れていく5体に入っている仲間も選べる
- **親のその後**：2体ともいなくなる
- **子の種族**：［親1の種族］［親2の種族］［別の種族］の3つから選ぶ
  - **別の種族**：決まった親の組（順番は問わない）からだけ生まれる。子は親2体より強い種族。組み合わせは fusion.ts の RECIPES
    | 親の組 | 子 |
    |---|---|
    | チュッピ＋ベロッグ | シュルル |
    | チュッピ＋シュルル | ガルフ |
    | パタリ＋ポコタケ | モヤリ |
    | シュルル＋ポコタケ | カブラム |
    | ベロッグ＋シュルル | ヒダマリ |
    | ガルフ＋パタリ | ヒダマリ |
    | カブラム＋ポコタケ | ゴロム |
    | ヒノコ＋パタリ | ヒイロドリ（配合でしか生まれない。以下同じ） |
    | ベロッグ＋クジラン | ミズチ |
    | ビリス＋ガルフ | ナルカミ |
    | ポコタケ＋ツチモグ | コダマ |
    | ネムリガ＋カマイタチ | ツムジ |
    | ホタリ＋フワクラ | コウリン |
    | ヨルネコ＋シュルル | ヌエ |
    | チュッピ＋ドスイノ | ユメバク |
  - 表にない組と、同じ種族どうしの組は、3つ目のボタンを「なし」にして押せなくする
  - まだ一度も別の種族で生んだことのない子は、ボタン・子の名前・顔を「？？？」にする（足し算・伸び・性格の確率は種族で変わらないので、そのまま出す）。一度生むと、次からは名前を出す（Profile.bred に覚える）
  - 別の種族の子は、親のニックネームを引き継がない
  - 強い魔物どうしの組（ガルフ＋ヒダマリなど）は、あとで配合でしか生まれない新しい魔物を足すときのために空けておく
- **子のレベル**：Lv1 から
- **子の性格**：親1の性格 35％、親2の性格 35％、残りの 30％ をほかの性格で同じだけ分ける
  - 例：親が「がんばりや」と「しんちょう」なら、その2つが 35％ ずつ、ほかの3つが 10％ ずつ
  - 親2体が同じ性格なら、その性格が 70％、ほかの4つが 7.5％ ずつ
- **配合回数**：親2体のうち大きい方 +1。名前に「ガルフ+3」のように出す（ログなど、仲間を呼ぶところすべて）。つよさ画面にも「配合　3回　伸び×1.15」と出す
- **強くなる分**
  1. **足し算**：親2体の今の最大HP・攻撃・防御を、それぞれ足した値の 5％ を、子にずっと残す（仲間の足し算の補正 `bonus` に足す）。親の足し算の分も、親の能力に入っているので一部が受け継がれる
  2. **伸び**：レベルが上がったときの伸びが、配合回数1回ごとに +5％。10回（+50％、1.5倍）で止める。配合回数そのものは、そのあとも増える
     - 例：ガルフ Lv50 は、今は HP148・攻撃69・防御24。+5 で HP180・攻撃84（×1.25）、+10 で HP212・攻撃100（×1.5）
- **配合の書**（📗）：めったに出ない道具。ささやきの森の B6F〜B15F と、しずくの氷穴の B6F〜B20F でまれに拾える。商店では、入れ替わる品にまれに並ぶ（3000ルーン）。ダンジョンでは使えない（投げる・置くはできる）。配合では倉庫の書から先に使う

### 9.3 転生（イヅツチだけ）
相棒のイヅツチは配合の親にできない代わりに、転生で強くなる。

- **使うもの**：転生の書1つと、1000ルーン、Lv10 以上のほかの魔物1体（その魔物はいなくなる）
- **子**：イヅツチのまま。Lv1 から
- **強くなる分**：配合と同じ（足し算は、イヅツチと魔物の能力を足した値の 5％。伸びは転生回数1回ごとに +5％、10回で止める）
- **性格**：配合と同じ決め方（イヅツチの性格 35％、魔物の性格 35％、残り 30％）
- **転生回数**：イヅツチの転生回数に +1。名前に「イヅツチ+2」のように出す。つよさ画面には「転生　2回　伸び×1.10」
- **画面**：［配合］の画面で［転生］に切り替え、イヅツチに合わせる魔物を1体選ぶ。転生後の見込みを出し、「イヅツチはLv1に戻ります　○○はいなくなります　転生しますか？」と聞いてから転生する。連れていく仲間からは外さない
- **特殊能力**：転生回数に応じて、イヅツチに特殊能力が増えていく（中身はあとで決める）
- **転生の書**（📙）：しずくの氷穴の B6F〜B20F でまれに拾える（森では出ない）。商店は配合の書と同じ。あとで、ボスを倒すと手に入る、などに変えるか考える

## 10. 画面構成と操作
### 10.1 ダンジョン画面（縦持ち）
- マップの表示範囲は11×11マス（暫定。実機で試して調整する）
```
┌─────────────────────────┐
│ B3F Lv5  HP■■■■□ 32/40  │ ← ステータス
│          MP■■□□□ 12/30  │
│          満腹 ■■■■□ 80%  │
├─────────────────────────┤
│ 🐺 18/20  🦇 5/12  🐸 --  │ ← 召喚中の仲間（最大3枠）
├─────────────────────────┤
│                         │
│   マップ（11×11マス）     │ ← 主人公が中央
│   右上に小さなミニマップ   │
│ ┌メッセージログ（2行）──┐ │ ← マップの下の端に重ねる
├─────────────────────────┤
│  ↖ ↑ ↗        [攻撃]     │
│  ← ● →    [魔法][カード]  │ ← 左：パッド／右：ボタン
│  ↙ ↓ ↘   [バッグ][メニュー]│
└─────────────────────────┘
```

- マップの広さ（2026-11-08、UIレビュー）：マップは遊びの中心なので、できるだけ高くする。ログは最後の2行だけを、マップの下の端に半透明の紺の札で重ねる（1行ずつ、長い文は「…」で切る。押すと、これまでのログが全部見られる）。仲間の枠は細く（高さ44px、顔36px）する。iPhone の Safari（390×664）で、マップの高さは約260px（前は約175px）
- 上の帯の右のルーンとターンは、画面の丸い角で欠けないよう少し内側に寄せる
- マップでは、主人公と仲間の足もとに緑の影、敵の魔物の足もとに赤い影を出して見分けやすくする。アイテムには影を付けない。影はHPの棒より上に出し、HPの棒には濃い色のふちを付けて重ならないようにする
- ステータスの左には、主人公の顔を丸い枠で出し、左下にレベルの札を付ける。仲間の枠も、丸い顔・レベルの札・HPの棒・状態異常の印にする。HPの数字の上に、いつも指示（ついてくる・待機・突撃・逃げる）を金の小さな字で出す。顔の絵がない魔物は絵文字を出す
- マップの主人公・仲間・魔物は動かす
  - 1マス歩くと、約0.12秒かけてなめらかに進み、小さく跳ねる。画面も一緒になめらかに動く
  - 立っている間は、息をするように少し伸び縮みする
  - 絵は左下を向いているので、右を向いたら左右を反転する。上下を向いたときは前の向きのまま
  - 主人公の向いている方向は、主人公のマスのふちに金の矢印でいつも出す。正面のマスを金の枠でうっすら強調するかは設定で選ぶ（はじめはオン）
- 見通し：マップの左上の［見通し］を押すたびにオン・オフを切り替える（ターンは使わない。オンの間はボタンが金の地になる）
  - オンの間は、今いる部屋の床のマスに線を引き、マス目を数えられるようにする。通路にいるときは、見えている近く（4マスまで）の床に線を引く
  - 自分から縦・横・斜めにまっすぐ並ぶマスには、うすい水色を付ける。矢や魔法が届く列と、魔物・道具までの距離を測るのに使う
- ダンジョンの中の見た目は、拠点と同じ紺と金の共通の部品（docs/art-guide.md 8.3）にそろえる
  - 上の帯・仲間の枠・ログは紺の地に金の線。階は拠点の見出しと同じ紺の札、顔の枠は金の縁に紺の台
  - 操作部は濃い紺の帯に金の上の線。パッドと［魔法］［仲間］［バッグ］［メニュー］は紺の小さなボタン（ななめは字を少し薄くする）、［攻撃］は空色の宝石の大きなボタン
  - 一覧・これまでのログ・確かめの窓は、四隅に金の唐草の紺の枠。一覧の行は拠点と同じ明るい紙の札、横いっぱいのボタンと［閉じる］［いいえ］は暗い紺のタブの板、確かめの［はい］は空色の宝石のボタン
  - Safari の上のバーの色は、ダンジョンでは上の帯と同じ紺、拠点では村の絵の空の色にする（index.html の theme-color を切り替える）
- マップの床と壁は石で描く（模様はプログラムで作る。あとで絵に差し替えられる）
  - 床は土に小石が埋まった模様。壁の上の面は丸い石を積んだ模様で、床と接するふちには明るい石を並べる
  - 床に面した壁には、手前に切り立った側面を描き、そばの床に壁の影を落とす
  - 壁の奥とマップの外も、黒くせずに同じ岩で描く。まだ見ていないマスは床も壁もそのまま描いて強く暗くし、通路の形がうっすら分かるようにする（見たことはあるが今は見えていないマスより暗い）
  - 階段は、床に開いた穴に石の段が下りていく絵にする
  - 明かり：主人公のまわりは明るく、離れるほど暗くする（真っ暗にはしない）。床に面した壁にときどきたいまつを掛け、炎をゆらして、まわりを暖かく照らす
  - 色・明かりの色・暗さ・たいまつの多さは、ダンジョンごとに決める（dungeons.ts の theme）。はじまりの洞窟は茶色の岩、ささやきの森は苔むした緑の石、しずくの氷穴は青白い氷の岩
  - 床と壁は階に入ったときに1枚の絵にまとめて描き、毎回はその見えているところを写すだけにする
- 階に入ったとき（ダンジョンに入ったときと、階段を降りたとき）は、紺の画面にダンジョンの名前（階は金の字）と「B2F」のような階を約1.6秒出す。最後に薄くなって消える。タップすると早く消える。出ている間は操作を受け付けない
- ミニマップの色：主人公は明るい緑、仲間は濃い緑、敵はピンク、アイテムは水色、階段は黄色

### 10.2 操作
| 操作 | 動作 |
|---|---|
| パッドの方向をタップ（今の向きと違う方向） | その方向へ振り向くだけ。ターンは使わない（メニューでオフにすると、すぐ進む） |
| パッドの方向をタップ（今の向きと同じ方向） | 1マス移動。敵がいる方向なら、向きを変えるだけで攻撃しない（ターンは使わない） |
| パッドの方向を長押し | ダッシュ。振り向いたあと、止まるところまで続けて進む（下の「ダッシュ」） |
| 仲間のいる方向へ進む | 設定（メニュー）で「入れ替わる」か「押す」を選ぶ。押すと仲間を1マス先へ押し出す。通路などで仲間が一列に並んでいれば、列ごとまとめて押す（いちばん先の仲間の前が空いているときだけ）。押せないときは入れ替わる |
| マップで隣の仲間をタップ | 「入れ替わる」か「押す」を選んで、その仲間の方へ進む（1ターン） |
| ダッシュ | 部屋の中はまっすぐ、通路は曲がり角に沿って進む。魔物が見えている、傷ついた、道具や階段の上に来た、部屋に出入りした、通路の分かれ道・行き止まりで止まる。止まったら、指を離してもう一度押すと続きを進む。混乱していてもダッシュできる（混乱ででたらめになるのは攻撃の向きだけ） |
| パッド中央● | 足踏み（1ターン待つ） |
| [攻撃]（短く押す） | 向いている方向に攻撃（指を離したときに攻撃する） |
| [攻撃]（長押し） | 約0.3秒で、ボタンの上に登録した道具の扇（左上・上・右上の3枠）が出る。指を滑らせて枠の上で離すと、その道具を使う（1ターン）。枠の外で離すと何もしない。0.3秒より前に離すとふつうの攻撃。長押しできることは、ボタンの上の角の「•••」で示し、押している間はボタンの下の金の線が伸び、伸びきると扇が出る。扇を出している間は、まわりを暗くする。初めてのダンジョンに入ったとき、一度だけログで「［攻撃］を長押しすると、登録した道具を使える」と知らせる |
| [魔法] | 魔法の一覧 → 選ぶと向いている方向に撃つ |
| [カード] | カードの一覧 → 召喚／戻す |
| 仲間の枠をタップ | その仲間に指示（ついてくる／待機／突撃／逃げる）。今の指示の行は金に光らせて「✓ ついてくる（指示中）」と出し、ボタンは出さない |
| [バッグ] | アイテムの一覧（同じ道具は「薬草 ×2」と1行にまとめる。行を押す）→ 使う／投げる／置く |

攻撃は、主人公・仲間・魔物の順に1回ずつ見せる。攻撃する側は種族ごとの動き方（噛みつく・突進する・飛びかかるなど、キャラクターの台帳で決める）で相手に迫り、受けた側は押されて揺れ、点滅し、火花が散ってダメージの数字が出る（1回およそ0.45秒）。たおれた者は沈みながら薄くなり、煙が立って消える。魔法は足もとに魔法陣を出して唱え、火の玉・炎・稲妻・光の盾などを見せる。炸裂の星は爆発し、画面が光って揺れる。舌・触手は伸びて縮み、火を吐くと炎が吹きつけ、いかずちは稲妻が走る。封印とレベルアップは光の柱が立つ。状態異常になると、そのマスに「混乱」「毒」などの文字と色の粒が出る。投げた物と矢は、道すじにそって飛んでから当たる。主人公がダメージを受けると画面が少し揺れる。見せている間は操作を受け付けないが、画面を押しても早送りはしない（2026-11-08 にやめた。速さは設定の「演出の速さ」で選ぶ）。1回の行動で見せる長さは2.6秒まで。演出の種類と長さは docs/effects.md。ログとHPも、その攻撃のところまでを出す。攻撃を受けた主人公と仲間は、攻撃してきた方を向く。
| [メニュー] | 足元、ログ全体、設定、中断（設定は拠点のその他でも変えられる） |

### 10.2.1 道具の登録
- バッグで道具を選び、［登録する］から3つの枠（左上・上・右上）のどれかに入れる。同じ枠でもう一度押すと外す
- 登録は種類でする。バッグのどの薬草でも使い、なくなれば次の同じ道具を使う。矢も同じ
- 登録できるのは使える道具すべて（矢・草・水・食料・印・星・魔導書・錬金釜）。武器・盾・白紙カードは登録できない
- 扇には絵文字とバッグにある数（×3、42本）を出す。バッグにない枠は薄く出し、選べない
- 矢は向いている方向に撃ち、草などは自分に使う。復活の印・召喚の印・錬金釜は選ぶ画面を出す。使えないときは理由をログに出す（ターンは使わない）
- 登録は拠点に戻っても残る。初めて遊ぶときは空

### 10.3 カード画面
- 5枚を一覧で表示：絵文字、名前、Lv、HP、召喚コスト、状態（待機／召喚中／瀕死）
- 待機のカードは「召喚」、召喚中のカードは「戻す」「指示」を選べる
- MPが足りないカードと瀕死のカードはグレー表示
- カードを押すと**つよさ**を見られる（6.3）。仲間の枠から開く指示の画面にも［つよさ］がある

### 10.4 拠点画面（MVPの簡易版）
- ダンジョンを選ぶ → 保管庫から持っていくカードを5枚まで選ぶ → 倉庫からバッグに持っていくアイテムを選ぶ → 出発
- **倉庫**：アイテムの出し入れが自由。ダンジョンから持ち帰ったアイテムもここにしまえる
- 習得済みの魔法の確認
- 容量（暫定）：バッグ40個、倉庫9999個（袋は中身にかかわらず1個）
- 今の作り
  - 初めて開いたとき、ダンジョンが終わったとき（踏破・力つきた）に拠点を開く。途中のダンジョンがあれば、続きから再開する
  - 冒険は、挑むダンジョンを選ぶところから始める（2026-11-08。魔物の Lv を見てから仲間を決められるように）。踏破済みは🏆、挑めるものは⚔️、まだ挑めないものは🔒と条件を出す。一覧は名前・踏破済みか未踏破か・階の数だけを出し、押すとそのダンジョンの詳しい画面（踏破したか・階の数・魔物の Lv・特徴・記録）を出す。詳しい画面の下には、確かめの窓と同じ並びで、左に［挑む］（空色）、右に［やめる］を置く。どちらも楕円の宝石のボタンで、［やめる］は赤。［挑む］で仲間と持ち物の準備へ進み（［やめる］で一覧へ）、下の［〇〇へ出発］で入る。準備のタブの左の「‹」で選び直せる。選んだダンジョンは拠点にいる間は覚えておき（ほかのタブへ移って戻っても準備から）、ダンジョンから戻ったら選び直す
  - あるダンジョンを初めて踏破すると、終わりの知らせに「○○に挑めるようになった」と出す
  - 拠点に入ると、まずトップを出す。ダンジョンから戻ったときもトップに戻る
  - **下のタブ**：［拠点］［冒険］［仲間］［商店］［その他］の5つ（配合は［仲間］の中。配合の画面でも［仲間］を選んでいる見た目にし、配合の「NEW」も［仲間］に付ける）。木の帯に、四角い枠に入ったアイコンと名前を並べ、選んでいるタブは金の枠と金の字にして少し浮かせ、ほかのタブのアイコンは少しくすませる。画面の幅に均等に並べる。どの画面からも1回で移れる
  - **見出し**：左に画面の名前（トップは「拠点」。2026-11-08 に、まん中の名札と同じ「初代 召喚士」を2か所に出すのをやめた。称号はまん中の名札に足す）。右に持っているルーン（左右がひし形の金の飾りの札）。どちらも紺の板に金の縁
  - どの画面も、村の一枚絵を背景にする。トップ以外は一覧が読みやすいよう、背景を少し暗くする

### 10.4.1 ルーンと商店
- お金は**ルーン**。ダンジョンの床に落ちていて、拾うとすぐ数が増える（バッグの空きは使わない）。物を売っても得られる
- ダンジョンで拾ったルーンは持ち歩き、拠点に戻ると持っているルーンに足す。上の表示に「💠12」のように出す。拠点のルーンはダンジョンに持っていかない
- 終わりの知らせに、持ち帰ったルーンと、力つきて失ったルーンを出す
- 商店は今は拠点のタブだけ。あとでダンジョンの中にも店を開く（品ぞろえと売り買いは src/game/shop.ts にまとめてあり、そのまま使える）
- **買う**
  - どの品も棚にある数までしか買えない（2026-11-08 に、薬草・パンをいくつでも買えるのをやめた）。薬草とパンは、いつも2つずつ並ぶ。装備品・魔導書・印・星は3〜5品が並び、1品につき1つ。棚の品は1つずつ1行に出し（薬草とパンは2行ずつ）、どの行も［＋］は1まで。買うと棚からなくなり、ダンジョンから戻るたびに並べ直す。強い印は出にくい。画面では、いつでも買える品と入れ替わる品を分けて書かない
  - 上で送り先を［🎒 バッグへ送る］［📦 倉庫へ送る］から選ぶ（数と入る数も出す）
  - 品ごとに［－］数［＋］で買う数を選ぶ。まん中の数を押すと、じかに打ち込める
  - 棚にある数は出さず、［＋］をその数までしか押せないようにする（数の箱に「0/1」と出すと、2桁で箱からはみ出すため）
  - ［＋］は、棚の数・ルーン・送り先の空きから、ほかの品で選んだ分を引いた数まで押せる。打ち込んだ数がそれをこえたら、数は変えずに値段の横に「n個まで」（今買える数）を赤で出す
  - 画面の下のボタン［n個を買う　💠合計］でまとめて買い、選んだ送り先へ入れる。数を選んでいる間は、上のルーンの札に買ったあとのルーンを「5000 → 4960」と出す（売るときも同じ）。何も選んでいないときは［買う品を選ぶ］（押せない）
  - 買えない品（ルーンが足りない・送り先がいっぱい）も［－］数［＋］を出し、行と一緒に暗くして［＋］を押せなくする
- 見た目：紺と金の共通の部品（docs/art-guide.md 8.2）。［買う］［売る］と送り先は紺のタブ、品は1行の形（10.4）で名前の横に💠値段、［－］［＋］は紺の小さなボタンでまん中の数は薄い紙の箱、下の［n個を買う］［n個を売る］は空色の宝石のボタン。買えない・売れない品は札ごとくすませる。買ったあと・売ったあとの知らせは、見出しの帯にせず金の字の文にする
- **売る**
  - ［🎒 バッグ］［📦 倉庫］を切り替える。タブにそれぞれの数を出す
  - 同じ道具は1行にまとめ（持ち物と同じ分け方。矢は束ごとに本数が違うので分ける）、買うときと同じ［－］数［＋］で売る数を選ぶ。数を押すと打ち込める。売れる数は名前の横の「×3」で分かり、こえたら「3個まで」を赤で出す
  - 画面の下のボタン［n個を売る　💠合計］でまとめて売る。何も選んでいないときは［売る品を選ぶ］（押せない）。売れない道具は［売れない］
  - 売り値は値打ちの3分の1。＋の付いた装備は高く、矢は本数ぶん
  - 中身の入った袋は売れない（先に中の道具を出す）
- 値打ち（買い値）は balance.md 9章
