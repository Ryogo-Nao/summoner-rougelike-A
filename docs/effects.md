# 演出の一覧

攻撃・魔法・道具の演出の決まり。キャラクターの台帳（docs/characters.md）と同じように、どんな演出があるかをここで見る。

- しくみ：src/render/effects.ts（段の長さ・粒・画面の揺れ）、src/render/renderer.ts（描き方）
- 場面を作るところ：src/game/state.ts の `scene()`。場面ごとに「何をしたか（action）」と「かかるマス（cells）」を持つ
- 演出の絵は作らず、コードで描く（光・粒・形）。生成AIの光る絵は、背景の緑をきれいに抜けないため

## 1. 場面の流れ

1つの場面は、3つの段で再生する。

| 段 | 中身 | 上のHP・ログ |
|---|---|---|
| 構える（windup） | 攻撃する者が相手の方へ踏み込んで戻る。投げる・撃つときは軽く構える | 前のまま |
| 飛ぶ（travel） | 投げた物・矢が、道すじにそって飛ぶ | 前のまま |
| 当たる（impact） | 受けた側が揺れて点滅し、火花が散り、数字が出る。主人公が受けると画面が少し揺れる | 当たったあとに変わる |

- 1回の行動で見せる場面の合計は、2.6秒まで。こえるときは全体を速める
- 場面の再生中に画面のどこかを押すと、残りを4倍の速さで早送りする
- 眠り・はりつけで動けず、自動でターンが進むときは2倍の速さ

## 2. 演出の速さ（設定）

ダンジョンのメニューと、拠点のその他の設定で切り替える。

| 設定 | 中身 |
|---|---|
| ふつう | 下の表の長さ |
| 速い | 半分の長さ |
| 最小 | 動きなし。数字のある場面だけ、0.16秒出す |

## 3. 演出の一覧

## 4. これからの順番

1. 土台（済み）：場面の種類と範囲、段の流れ、粒、画面の揺れ、演出の速さ、押して早送り、投げた物・矢が飛ぶ
2. 攻撃の動き：台帳に「動き方」の欄を足し、種族ごとに動かす（噛みつき・突進・浮遊・舌など）。2回攻撃・空振り・たおれる動き
3. 魔法と星：火の魔法・大火球・雷・守り・力・炸裂の星（食べた・投げた）
4. ほかの演出：舌・触手・火を吐く・いかずち・印・レベルアップ・状態異常にかかったとき
