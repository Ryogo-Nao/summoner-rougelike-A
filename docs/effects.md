# 演出の一覧

攻撃・魔法・道具の演出の決まり。キャラクターの台帳（docs/characters.md）と同じように、どんな演出があるかをここで見る。

- しくみ：src/render/effects.ts（段の長さ・粒・画面の揺れ）、src/render/renderer.ts（描き方）
- 場面を作るところ：src/game/state.ts の `scene()`。場面ごとに「何をしたか（action）」と「かかるマス（cells）」を持つ
- 演出の絵は作らず、コードで描く（光・粒・形）。生成AIの光る絵は、背景の緑をきれいに抜けないため

## 1. 場面の流れ

1つの場面は、3つの段で再生する。

| 段 | 中身 | 上のHP・ログ |
|---|---|---|
| 構える（windup） | 攻撃する者が動く。隣への攻撃は種族ごとの動き方（4章）、魔法などは踏み込んで戻る、投げる・撃つときは軽く構える | 前のまま |
| 飛ぶ（travel） | 投げた物・矢が、道すじにそって飛ぶ | 前のまま |
| 当たる（impact） | 受けた側が攻撃してきた方から押されて戻り、揺れて点滅し、火花が散り、数字が出る。主人公が受けると画面が少し揺れる。たおれた者は沈みながら小さく薄くなり、煙が立って消える | 当たったあとに変わる |

- 1回の行動で見せる場面の合計は、2.6秒まで。こえるときは全体を速める
- 場面の再生中に画面のどこかを押すと、残りを4倍の速さで早送りする
- 眠り・はりつけで動けず、自動でターンが進むときは2倍の速さ
- 2回攻撃の2回目（同じ者が同じ相手へ続けて攻撃する）は、構える段を6割の長さにして続けざまに見せる

## 2. 演出の速さ（設定）

ダンジョンのメニューと、拠点のその他の設定で切り替える。

| 設定 | 中身 |
|---|---|
| ふつう | 下の表の長さ |
| 速い | 半分の長さ |
| 最小 | 動きなし。数字のある場面だけ、0.16秒出す |

## 3. 演出の一覧

## 4. 攻撃の動き方

隣への攻撃は、1枚の絵をコードで動かす（進む・浮く・傾ける・伸び縮み）。どのキャラクターがどの動き方かは、キャラクターの台帳（src/game/characters.ts の motion、docs/characters.md の「動き方」）で決める。主人公は「薙ぎ払う」。

| 動き方 | 中身 | 合うキャラクター |
|---|---|---|
| 噛みつく（bite） | 少し引いて、前のめりに噛みつく | チュッピ・ヒダマリ・クイムシ |
| 突進する（charge） | 低く構えてためてから、深く突っ込む | ガルフ・ドスイノ |
| 飛びかかる（pounce） | かがんで山なりに飛び、着地でつぶれる。影は地面に残る | イヅツチ・ベロッグ・アミグモ |
| 急降下する（swoop） | 舞い上がってから、斜めに急降下する | パタリ |
| のしかかる（slam） | 伸び上がって、前へ倒れこむ | ポコタケ・ゴロム・ツブマル |
| 漂って触れる（float） | ふわりと寄り、揺れながら触れる | モヤリ・ネムリガ・フワクラ |
| 突き刺す（sting） | 引いてためて、すばやく突く | シュルル・カブラム・チスイ |
| 薙ぎ払う（swipe） | 振りかぶって前へ払う。相手のマスに斬った跡の弧が出る | 主人公・ヌラリカ・キリガニ・ツララグマ |

- 新しいキャラクターを足すときは、背景と見た目に合わせて台帳で動き方を選ぶ。合うものがなければ、src/render/effects.ts の motionPose に足す
- どの動き方も、構える段の 0.5〜0.6 ごろにいちばん相手に近づき、段の終わりで元の姿に戻る（F-77 で確かめる）

## 5. これからの順番

1. 土台（済み）：場面の種類と範囲、段の流れ、粒、画面の揺れ、演出の速さ、押して早送り、投げた物・矢が飛ぶ
2. 攻撃の動き（済み）：種族ごとの動き方、押される動き、斬った跡、たおれて消える動き、2回攻撃を続けざまに見せる
3. 魔法と星（済み）：火の魔法・大火球・雷・守り・力・炸裂の星（食べた・投げた）。魔法陣・火の玉・炎・稲妻・盾・爆発・画面の光り（src/render/spells.ts）
4. ほかの演出：舌・触手・火を吐く・いかずち・印・レベルアップ・状態異常にかかったとき
